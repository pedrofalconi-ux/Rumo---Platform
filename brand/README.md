# Rumo — Brand Kit

Este material foi extraído diretamente do código-fonte do produto (app mobile + dashboard web), ou seja, reflete exatamente o que já está implementado hoje. Serve como ponto de partida para compartilhar com designers, agências ou parceiros.

## O que tem aqui

- [`colors.md`](./colors.md) — paletas de cor (app mobile claro/escuro + dashboard web)
- [`typography.md`](./typography.md) — fontes e stacks tipográficas usadas
- [`logos/`](./logos) — logo, símbolo e ícone do app em SVG/PNG

## O que falta (não está no código, precisa ser adicionado manualmente)

- **Arquivo do Figma**: não temos acesso a nenhuma conta/projeto do Figma. Se existir um arquivo de protótipo, peça o link de compartilhamento (ou um export) para quem enviou a mensagem, e:
  - Cole o link em [`figma.md`](./figma.md) (crie o arquivo), ou
  - Exporte as telas/componentes como PNG/PDF e salve em uma pasta `brand/figma-export/`
- **Guideline de marca oficial (se existir um PDF/manual de marca)**: adicione o arquivo em `brand/guidelines/`
- **Fontes originais (arquivos .otf/.ttf)**, caso a equipe de design use uma fonte licenciada além das disponíveis no Google Fonts/sistema

## Como usar

Basta compartilhar a pasta `brand/` (ou subir num Google Drive/Notion) com quem pediu o material. Se algo mudar no código (cores, fontes), atualize os arquivos aqui também para não ficarem desatualizados.
